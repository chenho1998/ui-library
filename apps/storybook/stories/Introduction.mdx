# @yourorg/ui

A themeable, accessible React component library: **50 components** and **40 icons** built on `@yourorg/tokens`, with
Radix UI handling complex overlay, focus, keyboard and ARIA behaviour.

## Install

```bash
pnpm add @yourorg/ui
# Optional: use icons standalone without @yourorg/ui
pnpm add @yourorg/icons
```

```tsx
import '@yourorg/ui/styles.css';
import { ThemeProvider, Toaster, Button } from '@yourorg/ui';

export function App() {
  return (
    <ThemeProvider defaultColorScheme="system" storageKey="color-scheme">
      <Button>Hello</Button>
      <Toaster />
    </ThemeProvider>
  );
}
```

## Theming

```tsx
const acme = createTheme({
  brand: '#7c3aed',                         // generates the full brand palette
  tokens: { radius: { md: '6px' } },        // global token overrides
  colors: { dark: { bg: '#0b0b10' } },      // per-scheme semantic overrides
  components: { 'button-radius': '999px' }, // component tokens
});

<ThemeProvider theme={acme}>…</ThemeProvider>
```

Use the **Scheme**, **Theme** and **Font** toolbar buttons above to try light and dark, the built-in themes (anime,
pixel, brutalist, sketch and neon each restyle every component) and OpenDyslexic on any story.

- **Get started → Themes** shows every built-in theme side by side.
- **Get started → Usage guidelines** covers component selection, accessibility, controlled state and SSR.
- **Get started → Migration guide** documents upgrading to v0.3 and `@yourorg/icons`.
- **Patterns → App shell** puts the Sidebar, command palette and data components together.
