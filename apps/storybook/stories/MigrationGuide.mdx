## Upgrading to v0.3

### 1. Node.js 22+ for local development & tooling

Workspace tooling (Vitest 5, Stylelint 18, ESLint 10) now requires **Node 22.22.2+**, **24.15+**, or **26+**. Run `nvm use` in the repo root to pick up `.nvmrc` (`22`). Runtime browser support for published packages is unchanged (ES2020+, React 18.2+ or React 19).

### 2. Standalone `@yourorg/icons` package

Icons now live in their own tree-shakeable package, `@yourorg/icons` (40 icons + `createIcon`, `sideEffects: false`) — <a href="?path=/docs/foundations-icons--docs" target="_top">browse the Icons gallery</a>.

- **No breaking change**: Every icon and `createIcon` is still re-exported by name from `@yourorg/ui`.
- **Recommended for apps that only want icons**: install `@yourorg/icons` directly:

```tsx
// Still works:
import { CheckIcon, PlusIcon } from '@yourorg/ui';

// Lighter if you don't need full UI components:
import { CheckIcon, PlusIcon } from '@yourorg/icons';
```

### 3. Lighter `ScrollArea`, `Avatar`, and `Progress`

`ScrollArea`, `Avatar`, and `Progress` now use native browser primitives instead of Radix wrapper packages (saving ~5 KB gzipped and removing three dependencies):

- <a href="?path=/docs/overlays-utilities-kbd-scrollarea--docs" target="_top"><strong><code>ScrollArea</code></strong></a>: Uses native scrolling with `scrollbar-width: thin` and `scrollbar-color`. If you previously passed Radix-only props (`type`, `scrollHideDelay`), remove them—`orientation` (`'vertical' | 'horizontal' | 'both'`), `aria-label`, `ref`, and standard `div` props work identically.
- <a href="?path=/docs/data-display-tables-cards--docs" target="_top"><strong><code>Avatar</code></strong></a>: Same `src`, `name`, `size`, `shape` props, with zero React 19 fallback timer warnings in tests.
- <a href="?path=/docs/feedback-alerts-toasts--docs" target="_top"><strong><code>Progress</code></strong></a>: Same `value`, `max`, `label`, `showValue`, `size`, `tone` props and `role="progressbar"` ARIA attributes.

### 4. Consistent controlled/uncontrolled props and refs

- <a href="?path=/docs/navigation-layout-tabs-pagination--docs" target="_top"><code>Pagination</code></a> can now be used uncontrolled via `defaultPage` (`page` and `onPageChange` are optional).
- `Combobox`, `DatePicker`, `TimePicker`, and `DateRangePicker` (<a href="?path=/docs/inputs-actions-date-time-pickers--docs" target="_top">Date &amp; Time Pickers</a>) now accept `open`, `defaultOpen`, and `onOpenChange`.
- `Calendar` now accepts `defaultValue`, `month`, `onMonthChange`, and `ref`.
- `PinInput`, `FileUpload`, `Rating`, <a href="?path=/docs/data-display-treeview--docs" target="_top"><code>TreeView</code></a>, `Timeline.Item`, `DescriptionList.Item`, `Dialog.Body`/`Footer`, and <a href="?path=/docs/navigation-layout-sidebar--docs" target="_top"><code>Sidebar</code></a>`.Group`/`.Submenu` now all forward `ref`.
- <a href="?path=/docs/overlays-utilities-dialogs-drawers--docs" target="_top"><code>DropdownMenu</code></a> now supports nested submenus via `DropdownMenu.Sub`, `DropdownMenu.SubTrigger`, and `DropdownMenu.SubContent`.
- <a href="?path=/docs/feedback-alerts-toasts--docs" target="_top"><code>toast</code></a> adds `toast.info()`, `toast.warning()`, and `toast.promise(promise, { loading, success, error })`.

### 5. New components in v0.3

- <a href="?path=/docs/data-display-datatable--docs" target="_top"><strong><code>DataTable</code></strong></a> — sorting, search filtering, selection, bulk actions and pagination
- <a href="?path=/docs/data-display-carousel--docs" target="_top"><strong><code>Carousel</code></strong></a> — accessible slideshow with controls, dots, swipe and auto-play
- <a href="?path=/docs/inputs-actions-colorpicker--docs" target="_top"><strong><code>ColorPicker</code></strong></a> — hex picker with 2D saturation/brightness area, hue slider and swatches
- <a href="?path=/docs/navigation-layout-resizable--docs" target="_top"><strong><code>Resizable</code></strong></a> — split-pane layout with drag and WAI-ARIA window splitter keyboard controls
- <a href="?path=/docs/feedback-banner--docs" target="_top"><strong><code>Banner</code></strong></a> — full-width announcement strip (`subtle` and `solid` variants, optional `sticky`)
